Comercial Tech Brasil

Projeto de análise de dados comerciais desenvolvido com foco na simulação de atividades de um analista de dados em uma empresa fictícia do setor de tecnologia.

Objetivo

Construir uma base de dados comercial e realizar análises para compreender o comportamento de vendas, clientes, produtos e faturamento.

Tecnologias

- MySQL
- SQL
- Excel (etapa futura)
- Power BI (etapa futura)
- Python (quando necessário)

Estrutura do banco de dados

O banco utiliza as seguintes tabelas principais:

- "clientes"
- "produtos"
- "vendas"
- "itens_venda"

Também foi criada uma tabela auxiliar para controlar a frequência de compras dos clientes.

Volume de dados atual

- 354 clientes
- 150 produtos
- 4.000 vendas
- 12.184 registros em itens de venda

Análises desenvolvidas

- Faturamento total e ticket médio
- Desempenho por categoria de produtos
- Produtos com maior faturamento
- Distribuição das vendas por quantidade
- Identificação dos clientes com maior faturamento
- Investigação e correção de inconsistências nos dados

Status

Em desenvolvimento.

Observação: todos os dados utilizados são fictícios e foram criados para fins de estudo e simulação profissional.
